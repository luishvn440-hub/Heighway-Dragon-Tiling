# Heighway Dragon Tiling

An interactive, browser-based visualization of the **Heighway Dragon Curve** — a classic space-filling fractal — with four distinct rendering modes: Tiling, Boundary, Paper Fold, and L-System.

[Live Demo]((https://luishvn440-hub.github.io/Heighway-Dragon-Tiling/heighway-index.html)) (GitHub Pages)

---

## Overview

The Heighway Dragon (also called the Harter–Heighway Dragon or Jurassic Park Dragon) is a self-similar fractal curve with a fractal dimension of approximately **1.523627**. This project explores the curve from multiple mathematical perspectives:

| Mode | Description |
|------|-------------|
| **Tiling** | Renders 1, 2, or 4 rotated copies of the dragon curve that nestle together to tile the plane. Demonstrates the 90° rotational symmetry discovered by Harter in the 1960s. |
| **Boundary** | Visualizes the four sub-boundaries of the dragon using an **Iterated Function System (IFS)** chaos game. Each boundary component (red, blue, orange, green) is drawn with its own set of affine transformations. |
| **Paper Fold** | Generates the curve from the classic paper-folding turn sequence (L/R turns). Also overlays the exact perimeter of the polygon formed by the curve. |
| **L-System** | Renders the dragon via a Lindenmayer system with the grammar `X → +FX−−FY+`, `Y → −FX++FY−`. |

## Features

- **Interactive controls** — adjust iteration depth, number of copies, color scheme, stroke width, and more
- **Rainbow mode** — gradient coloring along the curve or point cloud
- **Lattice grid overlay** — show the underlying integer grid in Tiling mode
- **SVG export** — download the current view as a scalable vector graphic
- **Responsive layout** — works on desktop and mobile
- **No dependencies** — pure HTML, CSS, and vanilla JavaScript

## How It Works

### Tiling Mode
Four copies of the dragon curve, each rotated by multiples of 90°, share a common origin (the "tail") and fit together without gaps to tile the entire plane. At even iterations the lattice aligns with the axes; at odd iterations it is rotated 45°. As iterations grow, the four rotated copies cover ever more lattice points. In the limit, the tiling is exact and the dragon has area ½ (for a unit initial segment).

### Boundary Mode (IFS)
The boundary of the dragon is not a simple curve — it consists of four self-similar components. Each component is generated by a chaos game using three affine transformations:

| Component | Maps | Color |
|-----------|------|-------|
| Red | 3 affine maps | `#ef4444` |
| Blue | 3 affine maps | `#3b82f6` |
| Orange | 3 affine maps | `#f97316` |
| Green | 3 affine maps | `#22c55e` |

### Paper Fold Mode
The dragon curve can be generated by repeatedly folding a strip of paper in half and then unfolding it so each crease is at 90°. The resulting sequence of left/right turns directly determines the path of the curve on an integer grid.

### L-System Mode
The Lindenmayer system grammar for the dragon curve:
- **Axiom:** `FX`
- **Rules:**
  - `X → +FX−−FY+`
  - `Y → −FX++FY−`
- **Angle:** 45°
- **Draw:** `F` = forward, `+` = turn left, `−` = turn right

## Controls

| Control | Modes | Description |
|---------|-------|-------------|
| **Depth** | All | Iteration level (max varies by mode: up to 16 for Tiling/Paper Fold, 14 for L-System) |
| **Copies** | Tiling | Number of rotated dragon copies: 1, 2, or 4 |
| **Component** | Boundary | Show all four boundary components or isolate one |
| **Color Scheme** | Tiling, Paper Fold, L-System | Preset palette: Violet, Teal, Coral, Blue, Amber |
| **Stroke Width** | All | Line thickness or point size |
| **Rainbow** | All | Toggle gradient coloring |
| **Show Grid** | Tiling | Overlay the integer lattice grid |

## Mathematical Background

- **Fractal dimension:** ≈ 1.523627
- **Area (limit):** ½ (for unit initial segment)
- **Lattice step:** (1/√2)ⁿ at iteration *n*
- **Symmetry:** 90° rotational symmetry in the four-dragon tiling
- **Self-similarity:** The dragon can be decomposed into two smaller copies, each scaled by 1/√2 and rotated by ±45°
